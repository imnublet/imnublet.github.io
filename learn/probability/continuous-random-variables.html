Continuous random variables, CDFs and PDFs

The CDF works for every random variable. When it has a derivative, the density is probability per unit length.

Probability & multivariate data analysis 25 min Y&G ch. 4
After this lesson you can
  • define the CDF of any random variable and prove its four characteristic properties;
  • define a continuous random variable through its density and compute probabilities and moments by integration;
  • derive the moments of the uniform and exponential laws and the memorylessness of the exponential;
  • prove that inverse-transform sampling produces a given CDF, using the generalised inverse.

§ 01 DefinitionThe cumulative distribution function

A PMF is useless for a voltage or a waiting time: each exact value has probability zero. One object describes the distribution of every random variable, discrete or not.

DefinitionCDF

The cumulative distribution function of a random variable $X$ is

$$F_X(x) = \P[X \le x], \qquad x \in \R. \tag{1}$$

This is defined for every $x$ because $\{X \le x\}$ is an event, which is exactly the requirement in the definition of a random variable (lesson 2.1).

Theorem 1properties of a CDF
  1. $F_X$ is non-decreasing, and $\P[a < X \le b] = F_X(b) - F_X(a)$ for $a < b$;
  2. $\lim_{x \to -\infty} F_X(x) = 0$ and $\lim_{x \to \infty} F_X(x) = 1$;
  3. $F_X$ is right-continuous: $\lim_{h \downarrow 0} F_X(x + h) = F_X(x)$;
  4. $F_X$ has left limits, $F_X(x^-) = \P[X < x]$, so $\P[X = x] = F_X(x) - F_X(x^-)$: jumps are atoms.
Proof

(a) For $a < b$, $\{X \le b\}$ is the disjoint union of $\{X \le a\}$ and $\{a < X \le b\}$, so $F_X(b) = F_X(a) + \P[a < X \le b] \ge F_X(a)$.

Because $F_X$ is monotone, each one-sided limit exists and equals the limit along any monotone sequence approaching the point, so it suffices to use sequences and the continuity theorem (lesson 1.2, Theorem 4).

(b) $\{X \le -n\} \downarrow \bigcap_n \{X \le -n\} = \varnothing$ (no real number is $\le -n$ for all $n$), so $F_X(-n) \to 0$. And $\{X \le n\} \uparrow \bigcup_n \{X \le n\} = \Omega$, so $F_X(n) \to 1$.

(c) $\{X \le x + 1/n\} \downarrow \bigcap_n \{X \le x + 1/n\} = \{X \le x\}$, so $F_X(x + 1/n) \to F_X(x)$.

(d) $\{X \le x - 1/n\} \uparrow \bigcup_n \{X \le x - 1/n\} = \{X < x\}$, so $F_X(x - 1/n) \to \P[X < x]$. Then $\P[X = x] = \P[X \le x] - \P[X < x]$. ∎

The converse also holds: every function with properties (a)–(c) is the CDF of some random variable (Theorem 4 below constructs one). For a discrete $X$ the CDF is a staircase, $F_X(x) = \sum_{y \le x} P_X(y)$, rising by $P_X(y)$ at each $y \in S_X$ and flat in between. Right-continuity is the convention that the value at a jump is the top of the step.

§ 02 DensitiesContinuous random variables

Definitioncontinuous random variable, PDF

$X$ is a continuous random variable if there is a function $f_X \ge 0$, its probability density function, with

$$F_X(x) = \int_{-\infty}^{x} f_X(u) \d u \quad \text{for all } x \in \R. \tag{2}$$
Theorem 2working with a density
  1. $\int_{-\infty}^{\infty} f_X(x) \d x = 1$;
  2. $\P[a < X \le b] = \int_a^b f_X(x) \d x$, and $\P[X = x] = 0$ for every $x$;
  3. at every point $x$ where $f_X$ is continuous, $F_X'(x) = f_X(x)$.
Proof

(a) Let $x \to \infty$ in (2) and use Theorem 1(b). (b) $F_X(b) - F_X(a) = \int_a^b f_X$ by (2) and additivity of the integral; this is $\P[a < X \le b]$ by Theorem 1(a). $F_X$ is continuous because it is an integral of an integrable function, so by Theorem 1(d) $\P[X = x] = F_X(x) - F_X(x^-) = 0$. (c) is the fundamental theorem of calculus applied to (2). ∎

Because single points carry no probability, $\le$ and $<$ are interchangeable for continuous variables: $\P[a \le X \le b] = \P[a < X < b]$. The density is not a probability. It is a probability per unit length, $\P[x < X \le x + \Delta] = f_X(x)\Delta + o(\Delta)$ at continuity points, and it can exceed 1: Uniform$(0, \tfrac12)$ has density $2$ on its support. Changing $f_X$ at finitely many points (or on any set of length zero) changes no probability, so densities are only defined "almost everywhere".

Definitionexpectation of a continuous random variable

If $\int |x| f_X(x) \d x < \infty$, then $\E[X] = \int_{-\infty}^{\infty} x\, f_X(x) \d x$. More generally, for $g$ with $\int |g(x)| f_X(x) \d x < \infty$,

$$\E[g(X)] = \int_{-\infty}^{\infty} g(x)\, f_X(x) \d x. \tag{3}$$

Equation (3) is the continuous law of the unconscious statistician. Its proof for general $g$ needs the measure-theoretic integral; we take it as given (for monotone differentiable $g$ it follows from the change of variables in lesson 3.4). Everything proved in lesson 2.2 from (2) of that lesson carries over with sums replaced by integrals: linearity, $\Var[X] = \E[X^2] - \mu_X^2$, the MSE identity, and Markov and Chebyshev. The tail-sum formula becomes $\E[X] = \int_0^\infty \P[X > x] \d x$ for $X \ge 0$ (exercise 5).

Worked example 2.3.1from a density to a CDF, a probability and moments
Problem

$X$ has density $f_X(x) = c\,(1 - x^2)$ for $-1 \le x \le 1$ and $0$ elsewhere. Find $c$, the CDF $F_X$, $\P[|X| > \frac12]$, $\E[X]$ and $\Var[X]$.

Approach

The standard sequence: normalise (Theorem 2(a)), integrate the density from the left to get the CDF (2), read probabilities as CDF differences (Theorem 1(a)), and compute moments with (3). Use symmetry wherever possible.

Solution

  1. Normalise. $\int_{-1}^1 (1 - x^2)\d x = 2 - \frac23 = \frac43$, so $c = \frac34$.

  2. CDF. For $-1 \le x \le 1$, $$F_X(x) = \int_{-1}^{x}\tfrac34(1 - u^2)\d u = \tfrac34\Big[u - \tfrac{u^3}3\Big]_{-1}^{x} = \tfrac12 + \tfrac34 x - \tfrac14 x^3,$$ with $F_X = 0$ for $x < -1$ and $F_X = 1$ for $x > 1$. Check: $F_X(-1) = 0$, $F_X(1) = 1$.

  3. Probability. $\P[|X| > \tfrac12] = F_X(-\tfrac12) + 1 - F_X(\tfrac12)$. Since $F_X(\frac12) = \frac12 + \frac38 - \frac1{32} = \frac{27}{32}$ and $F_X(-\frac12) = 1 - \frac{27}{32} = \frac5{32}$ by symmetry, $\P[|X| > \frac12] = \frac{5}{32} + \frac{5}{32} = \frac{5}{16}$.

  4. Moments. $f_X$ is even, so $x f_X(x)$ is odd and $\E[X] = 0$. Then $$\Var[X] = \E[X^2] = \tfrac34\int_{-1}^1 (x^2 - x^4)\d x = \tfrac34\Big(\tfrac23 - \tfrac25\Big) = \tfrac34 \cdot \tfrac4{15} = \tfrac15.$$

Result

$c = \frac34$, $F_X(x) = \frac12 + \frac34x - \frac14x^3$ on $[-1, 1]$, $\P[|X| > \frac12] = \frac5{16}$, $\E[X] = 0$, $\Var[X] = \frac15$. (A Uniform$(-1, 1)$ variable has variance $\frac13$: this density puts less mass near the ends, so it is less spread.)

§ 03 FamiliesUniform and exponential

Theorem 3uniform and exponential laws

Uniform$(a, b)$: $f_X(x) = \frac{1}{b-a}$ on $(a, b)$ and $0$ elsewhere. Then $\E[X] = \frac{a+b}{2}$ and $\Var[X] = \frac{(b-a)^2}{12}$.

Exponential$(\lambda)$, $\lambda > 0$: $f_X(x) = \lambda e^{-\lambda x}$ for $x \ge 0$ and $0$ otherwise. Then $F_X(x) = 1 - e^{-\lambda x}$ for $x \ge 0$, $\E[X] = 1/\lambda$, $\Var[X] = 1/\lambda^2$, and $X$ is memoryless:

$$\P[X > s + t \mid X > s] = \P[X > t] \quad \text{for all } s, t \ge 0. \tag{4}$$
Proof

Uniform. $\E[X] = \frac{1}{b-a}\int_a^b x \d x = \frac{b^2 - a^2}{2(b-a)} = \frac{a+b}{2}$. Since variance is shift invariant, compute it for $Y = X - \frac{a+b}{2}$, uniform on $(-h, h)$ with $h = \frac{b-a}{2}$: $\E[Y^2] = \frac{1}{2h}\int_{-h}^{h} y^2 \d y = \frac{h^2}{3} = \frac{(b-a)^2}{12}$.

Exponential. $F_X(x) = \int_0^x \lambda e^{-\lambda u} \d u = 1 - e^{-\lambda x}$. For the moments, integrate by parts with $\int_0^\infty x^n \lambda e^{-\lambda x} \d x = \big[-x^n e^{-\lambda x}\big]_0^\infty + n\int_0^\infty x^{n-1}e^{-\lambda x} \d x$. The boundary term vanishes for $n \ge 1$, so $\E[X^n] = \frac{n}{\lambda}\E[X^{n-1}]$, and by induction from $\E[X^0] = 1$, $\E[X^n] = n!/\lambda^n$. Hence $\E[X] = 1/\lambda$ and $\Var[X] = 2/\lambda^2 - 1/\lambda^2 = 1/\lambda^2$.

Memorylessness. $\P[X > x] = e^{-\lambda x}$, and $\{X > s+t\} \subseteq \{X > s\}$, so $\P[X > s+t \mid X > s] = e^{-\lambda(s+t)}/e^{-\lambda s} = e^{-\lambda t}$. ∎

The exponential is the continuous counterpart of the geometric law: if a Bernoulli trial with success probability $\lambda\delta$ happens every $\delta$ seconds, the waiting time $\delta L$ satisfies $\P[\delta L > t] = (1 - \lambda\delta)^{\lfloor t/\delta \rfloor} \to e^{-\lambda t}$ as $\delta \to 0$, by the same limit as in the Poisson theorem of lesson 2.1. It is also the only continuous law with property (4) (exercise 4).

Worked example 2.3.2a component that has already survived
Problem

A component's lifetime $T$ (hours) is exponential with mean $1000$. (a) Find $\P[T > 1500]$. (b) The component has run for $1000$ hours without failing. Find the probability it lasts at least another $500$. (c) Find the time $t$ by which $90\%$ of components have failed.

Approach

Translate "mean 1000" into the rate, use the survival function $\P[T > t] = e^{-\lambda t}$ for (a), the memoryless property (4) for (b), and invert the CDF for (c).

Solution

  1. Parameter. $\E[T] = 1/\lambda = 1000$, so $\lambda = 10^{-3}$ per hour, and $\P[T > t] = e^{-t/1000}$.

  2. (a). $\P[T > 1500] = e^{-1.5} \approx 0.223$.

  3. (b). By (4) with $s = 1000$, $t = 500$: $\P[T > 1500 \mid T > 1000] = \P[T > 500] = e^{-0.5} \approx 0.607$. Directly: $\frac{e^{-1.5}}{e^{-1}} = e^{-0.5}$.

  4. (c). Solve $F_T(t) = 1 - e^{-t/1000} = 0.9$: $t = 1000\ln 10 \approx 2303$ hours.

Result

(a) $0.223$, (b) $0.607$, (c) $\approx 2303$ h. In (b) the $1000$ hours already survived are irrelevant: an exponential component does not age. This is a modelling claim worth questioning for anything that wears out.

§ 04 SimulationInverse-transform sampling

Every random-number library starts from (approximately) uniform numbers on $(0,1)$. The CDF is the bridge to any other law. When $F$ is continuous and strictly increasing, $F^{-1}$ exists and $\P[F^{-1}(U) \le x] = \P[U \le F(x)] = F(x)$. To handle jumps and flat pieces we need a more careful inverse.

Definitiongeneralised inverse (quantile function)

For a CDF $F$ and $u \in (0, 1)$, let $F^{-}(u) = \inf\{x \in \R : F(x) \ge u\}$.

Theorem 4inverse-transform sampling

Let $F$ satisfy (a)–(c) of Theorem 1. For $u \in (0,1)$ and $x \in \R$,

$$F^{-}(u) \le x \iff u \le F(x). \tag{5}$$

Consequently, if $U \sim \text{Uniform}(0,1)$, then $X = F^{-}(U)$ has CDF $F$.

Proof

Fix $u \in (0,1)$ and let $A_u = \{x : F(x) \ge u\}$. By (b), $F(x) \to 1 > u$ as $x \to \infty$, so $A_u \ne \varnothing$; and $F(x) \to 0 < u$ as $x \to -\infty$, so $A_u$ is bounded below. Hence $F^{-}(u) = \inf A_u$ is a finite real number. Because $F$ is non-decreasing, $A_u$ is an interval unbounded to the right ($x \in A_u$, $y > x$ $\Rightarrow$ $y \in A_u$). It contains its infimum: take $x_n \in A_u$ with $x_n \downarrow F^{-}(u)$; by right-continuity $F(F^{-}(u)) = \lim_n F(x_n) \ge u$. So $A_u = [F^{-}(u), \infty)$.

Now (5) is just a restatement: $u \le F(x) \iff x \in A_u \iff x \ge F^{-}(u)$.

For the consequence, $U \in (0,1)$ with probability one, so by (5) $\P[F^{-}(U) \le x] = \P[U \le F(x)] = F(x)$, the last step because $\P[U \le t] = t$ for $t \in [0,1]$. ∎

For the exponential, $F^{-}(u) = -\ln(1-u)/\lambda$, and since $1 - U$ is also uniform, $-\ln U / \lambda$ works too. For a discrete law, $F^{-}(U)$ is "walk up the staircase until it first reaches $U$", which is how the geometric sampler in the lesson 2.2 demo works. Sampling a law reduces to computing its quantile function, which is how scipy.stats' ppf is used in practice, and how normalising flows and copulas move between distributions.

Worked example 2.3.3samplers for a Pareto and a three-point law
Problem

Use inverse-transform sampling to write a sampler for (a) the Pareto law $F(x) = 1 - (x_m/x)^\alpha$ for $x \ge x_m$ (and $0$ below), with $x_m, \alpha > 0$, and (b) the discrete law $P(0) = 0.2$, $P(1) = 0.5$, $P(2) = 0.3$.

Approach

Compute $F^{-}(u) = \inf\{x : F(x) \ge u\}$. For a continuous, strictly increasing $F$ this is the ordinary inverse: solve $F(x) = u$. For a step function, read off where the CDF first reaches $u$. Then Theorem 4 says $F^{-}(U)$ has CDF $F$.

Solution

  1. (a) Invert. For $u \in (0, 1)$, $1 - (x_m/x)^\alpha = u \iff x = x_m (1 - u)^{-1/\alpha}$. $F$ is continuous and strictly increasing on $[x_m, \infty)$, so $F^{-}(u) = x_m(1 - u)^{-1/\alpha}$.

  2. (a) Simplify. $1 - U \sim \text{Uniform}(0, 1)$ too, so $X = x_m U^{-1/\alpha}$ has the same law.

  3. (b) The CDF. $F(x) = 0$ for $x < 0$, $0.2$ on $[0, 1)$, $0.7$ on $[1, 2)$, $1$ for $x \ge 2$.

  4. (b) Generalised inverse. The smallest $x$ with $F(x) \ge u$ is $0$ if $u \le 0.2$, $1$ if $0.2 < u \le 0.7$, and $2$ if $u > 0.7$. So $\P[X = 1] = \P[0.2 < U \le 0.7] = 0.5$, and similarly for the other values. ✓

Result

(a) $X = x_m U^{-1/\alpha}$; (b) $X = \ind\{U > 0.2\} + \ind\{U > 0.7\}$. The discrete case is just "cut $(0,1)$ into intervals of lengths $P(x)$ and see where $U$ lands", which is how every categorical sampler works.

§ 06 PracticeExercises

  1. $X$ has density $f_X(x) = c\,x^2$ on $[0, 1]$ and $0$ elsewhere. Find $c$, $F_X$, $\E[X]$ and $\Var[X]$.core

    Solution

    $\int_0^1 cx^2 \d x = c/3 = 1$, so $c = 3$. $F_X(x) = x^3$ on $[0,1]$, $0$ below, $1$ above. $\E[X] = \int_0^1 3x^3 \d x = \tfrac34$, $\E[X^2] = \int_0^1 3x^4 \d x = \tfrac35$, so $\Var[X] = \tfrac35 - \tfrac9{16} = \tfrac{3}{80}$.

  2. Find the median of Exponential$(\lambda)$ and compare it with the mean.core

    Solution

    $1 - e^{-\lambda m} = \tfrac12$ gives $m = \ln 2/\lambda \approx 0.693/\lambda$, below the mean $1/\lambda$: the long right tail pulls the mean up.

  3. (Probability integral transform.) If $F_X$ is continuous, show that $F_X(X) \sim \text{Uniform}(0,1)$.core

    Solution

    For $u \in (0,1)$, $\{F_X(X) \ge u\} = \{X \ge F_X^{-}(u)\}$ by (5) with $x = X$. Continuity of $F_X$ means $\P[X = x] = 0$ for all $x$, and $F_X(F_X^{-}(u)) = u$: the proof of Theorem 4 gives $\ge$, and since $F_X(x) < u$ for every $x < F_X^{-}(u)$, left-continuity gives $\le$. Hence $\P[F_X(X) \ge u] = 1 - F_X(F_X^{-}(u)) = 1 - u$, so $\P[F_X(X) < u] = u$, and $F_X(X)$ is uniform. This is why p-values of continuous test statistics are uniform under the null.

  4. Show that a non-negative random variable with $G(t) = \P[X > t] > 0$ for all $t$ that satisfies (4) must be exponential.stretch

    Solution

    (4) says $G(s+t) = G(s)G(t)$. Let $g = \ln G$, so $g(s+t) = g(s) + g(t)$ on $[0, \infty)$ (Cauchy's functional equation). By induction $g(n t) = n g(t)$, so $g(m/n) = \frac mn g(1)$ for positive integers $m, n$: $g(q) = q\,g(1)$ on the positive rationals. $G$ is non-increasing, hence so is $g$, and a monotone function equal to $q\,g(1)$ on a dense set is $t\,g(1)$ everywhere (squeeze between rationals). With $\lambda = -g(1) = -\ln G(1) \ge 0$, $G(t) = e^{-\lambda t}$; $\lambda > 0$ since $G(t) \to 0$ as $t \to \infty$ by Theorem 1(b).

  5. For $X \ge 0$ continuous with $\E[X] < \infty$, prove $\E[X] = \int_0^\infty \P[X > x] \d x$.stretch

    Solution

    Write $x = \int_0^x \d t = \int_0^\infty \ind\{t < x\} \d t$ and swap the order of integration (Tonelli, the integrand is non-negative): $$\int_0^\infty x f_X(x) \d x = \int_0^\infty \!\! \int_0^\infty \ind\{t < x\} f_X(x) \d x \d t = \int_0^\infty \P[X > t] \d t.$$ For the exponential this gives $\int_0^\infty e^{-\lambda t} \d t = 1/\lambda$ in one line.
