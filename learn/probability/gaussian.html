The Gaussian random variable

One density, two parameters, and tails that fall faster than any exponential.

Probability & multivariate data analysis 25 min Y&G ch. 4
After this lesson you can
  • prove that the Gaussian density integrates to one, and derive its mean and variance;
  • standardise any Gaussian and compute its probabilities with $\Phi$ and $Q$;
  • bound the Gaussian tail from above and below and know how sharp each bound is;
  • prove Stein's identity and use it to get every Gaussian moment.

§ 01 DefinitionThe Gaussian density

DefinitionGaussian random variable

$X$ is Gaussian (normal) with parameters $\mu \in \R$ and $\sigma > 0$, written $X \sim \mathcal N(\mu, \sigma^2)$, if

$$f_X(x) = \frac{1}{\sqrt{2\pi\sigma^2}}\, e^{-(x - \mu)^2 / 2\sigma^2}, \qquad x \in \R. \tag{1}$$

The standard normal is $Z \sim \mathcal N(0,1)$, with density $\phi(z) = \frac{1}{\sqrt{2\pi}}e^{-z^2/2}$ and CDF $\Phi(z) = \int_{-\infty}^z \phi(t) \d t$.

The Gaussian earns its place for two reasons that later lessons make precise. Sums of many small independent effects are approximately Gaussian whatever the effects' own laws (the central limit theorem, lesson 4.6), so measurement noise usually is. And Gaussians are closed under every linear operation we will apply to them (lesson 4.4), so models built from them stay tractable. Among all laws with a given variance, it also has maximal entropy, which makes it the least committal choice when only the first two moments are known.

First, (1) has to be a valid density. The difficulty is that $e^{-x^2/2}$ has no elementary antiderivative, so the normalising constant needs a trick.

Theorem 1Gaussian integral $$\int_{-\infty}^{\infty} e^{-x^2/2} \d x = \sqrt{2\pi}. \tag{2}$$
Proof

Call the integral $I$; it is finite (the integrand is below $e^{1/2 - |x|}$, since $x^2/2 \ge |x| - 1/2$) and positive. Square it and write the product as a double integral, which is legitimate for a non-negative integrand (Tonelli):

$$I^2 = \int_{-\infty}^\infty e^{-x^2/2} \d x \int_{-\infty}^\infty e^{-y^2/2} \d y = \iint_{\R^2} e^{-(x^2 + y^2)/2} \d x \d y.$$

Change to polar coordinates $x = r\cos\theta$, $y = r\sin\theta$, whose Jacobian determinant is $r$:

$$I^2 = \int_0^{2\pi} \!\! \int_0^\infty e^{-r^2/2}\, r \d r \d\theta = 2\pi \Big[-e^{-r^2/2}\Big]_0^\infty = 2\pi.$$

The factor $r$ is what makes the inner integral elementary. Since $I > 0$, $I = \sqrt{2\pi}$. ∎

With the substitution $z = (x - \mu)/\sigma$, $\d x = \sigma \d z$, the integral of (1) becomes $\int \phi(z) \d z = 1$ by (2). So (1) is a density for every $\mu$ and $\sigma > 0$.

Theorem 2standardisation, mean and variance

$X \sim \mathcal N(\mu, \sigma^2)$ if and only if $Z = (X - \mu)/\sigma \sim \mathcal N(0,1)$. Moreover $\E[Z] = 0$, $\Var[Z] = 1$, and therefore $\E[X] = \mu$, $\Var[X] = \sigma^2$.

Proof

Standardisation. If $X \sim \mathcal N(\mu, \sigma^2)$, then for any $z$, substituting $t = (x - \mu)/\sigma$,

$$\P[Z \le z] = \P[X \le \mu + \sigma z] = \int_{-\infty}^{\mu + \sigma z} \frac{1}{\sigma}\,\phi\Big(\frac{x - \mu}{\sigma}\Big) \d x = \int_{-\infty}^{z} \phi(t) \d t = \Phi(z).$$

The converse is the same computation read backwards: if $Z \sim \mathcal N(0,1)$ then $\P[\mu + \sigma Z \le x] = \Phi((x - \mu)/\sigma)$, and differentiating gives (1).

Moments of $Z$. $\int |z|\phi(z) \d z = 2\int_0^\infty z\phi(z)\d z = 2\big[-\phi(z)\big]_0^\infty = 2\phi(0) < \infty$, so $\E[Z]$ exists, and it is $0$ because $z\phi(z)$ is odd. For the second moment use $\phi'(z) = -z\phi(z)$ and integrate by parts with $u = z$, $\d v = z\phi(z)\d z$, $v = -\phi(z)$:

$$\E[Z^2] = \int_{-\infty}^\infty z \cdot z\phi(z) \d z = \Big[-z\phi(z)\Big]_{-\infty}^{\infty} + \int_{-\infty}^\infty \phi(z) \d z = 0 + 1.$$

So $\Var[Z] = 1$. Since $X = \mu + \sigma Z$, lesson 2.2's linearity and $\Var[aZ + b] = a^2\Var[Z]$ give the rest. ∎

So every Gaussian probability is a standard-normal probability: $\P[a < X \le b] = \Phi\big(\tfrac{b - \mu}{\sigma}\big) - \Phi\big(\tfrac{a - \mu}{\sigma}\big)$. By the symmetry $\phi(-z) = \phi(z)$, $\Phi(-z) = 1 - \Phi(z)$, so tables and code only need $z \ge 0$. The probability of landing within $1, 2, 3$ standard deviations of the mean is $2\Phi(k) - 1 = 0.6827,\ 0.9545,\ 0.9973$.

Worked example 2.4.1resistor tolerances
Problem

Resistors from a production line have resistance $X \sim \mathcal N(100, 2^2)$ ohms. (a) What fraction lies in $(97, 104]$? (b) Find the symmetric tolerance $t$ such that $95\%$ of resistors satisfy $|X - 100| \le t$.

Approach

Every Gaussian question reduces to the standard normal by Theorem 2: subtract the mean, divide by the standard deviation, and read $\Phi$ from a table or a library. For (b), run the same steps backwards with the quantile $\Phi^{-1}$.

Solution

  1. Standardise. $Z = (X - 100)/2 \sim \mathcal N(0, 1)$, and $97 < X \le 104 \iff -1.5 < Z \le 2$.

  2. (a) Evaluate. $\P[97 < X \le 104] = \Phi(2) - \Phi(-1.5) = \Phi(2) - (1 - \Phi(1.5)) = 0.97725 - 0.06681 = 0.9104$, using $\Phi(-z) = 1 - \Phi(z)$ (symmetry of $\phi$).

  3. (b) Set up. $\P[|X - 100| \le t] = \P[|Z| \le t/2] = 2\Phi(t/2) - 1$. Setting this to $0.95$ gives $\Phi(t/2) = 0.975$.

  4. (b) Invert. $\Phi^{-1}(0.975) = 1.960$, so $t = 2 \times 1.960 = 3.92$ ohms.

Result

(a) $\approx 91.0\%$; (b) $t \approx 3.92\,\Omega$, i.e. "$\mu \pm 1.96\sigma$ holds $95\%$". The same two moves, standardise then read $\Phi$ or $\Phi^{-1}$, solve essentially every one-dimensional Gaussian exercise.

§ 02 TailsThe Q-function and its bounds

Communications and statistics care mostly about the upper tail,

$$Q(z) = \P[Z > z] = 1 - \Phi(z) = \tfrac12 \operatorname{erfc}\big(z/\sqrt2\big), \tag{3}$$

where $\operatorname{erfc}(x) = \frac{2}{\sqrt\pi}\int_x^\infty e^{-t^2}\d t$ is the function numerical libraries implement accurately. $Q$ has no closed form, but it is pinned down very tightly by elementary functions.

Theorem 3Gaussian tail bounds

For every $z > 0$,

$$\frac{z}{1 + z^2}\,\phi(z) \;\le\; Q(z) \;\le\; \frac{\phi(z)}{z}, \tag{4}$$

and for every $z \ge 0$,

$$Q(z) \le \tfrac12\, e^{-z^2/2}. \tag{5}$$
Proof

Upper bound in (4). On the range of integration $t \ge z > 0$, so $1 \le t/z$:

$$Q(z) = \int_z^\infty \phi(t) \d t \le \int_z^\infty \frac tz\,\phi(t) \d t = \frac1z\Big[-\phi(t)\Big]_z^\infty = \frac{\phi(z)}{z}.$$

Lower bound in (4). Differentiate $-\phi(t)/t$ using $\phi'(t) = -t\phi(t)$: $\frac{\d}{\d t}\big(-\phi(t)/t\big) = \phi(t) + \phi(t)/t^2 = (1 + t^{-2})\phi(t)$. Integrating from $z$ to $\infty$,

$$\frac{\phi(z)}{z} = \int_z^\infty \Big(1 + \frac1{t^2}\Big)\phi(t) \d t \le \Big(1 + \frac1{z^2}\Big)\int_z^\infty \phi(t)\d t = \frac{1 + z^2}{z^2}\,Q(z),$$

since $t^{-2} \le z^{-2}$ for $t \ge z$. Rearranging gives the lower bound.

Bound (5). Substitute $t = z + s$ and expand $(z+s)^2/2 = z^2/2 + zs + s^2/2$, so $\phi(z + s) = e^{-z^2/2}e^{-zs}\phi(s)$ and

$$Q(z) = e^{-z^2/2}\int_0^\infty e^{-zs}\phi(s) \d s \le e^{-z^2/2}\int_0^\infty \phi(s) \d s = \tfrac12 e^{-z^2/2},$$

using $e^{-zs} \le 1$ for $z, s \ge 0$. ∎

The two bounds in (4) differ by the factor $z^2/(1+z^2)$, which tends to $1$, so $Q(z) \sim \phi(z)/z$ as $z \to \infty$: the relative error of the upper bound is below $1\%$ for $z > 10$ and below $10\%$ for $z > 3$. Bound (5) is looser by the factor $\sim z\sqrt{\pi/2}$ but needs no division by $z$, and it is the shape the Chernoff bound will give for sums in lesson 4.5. The headline is the $e^{-z^2/2}$: the Gaussian tail decays faster than any exponential $e^{-cz}$, which is why "$5\sigma$" events are about one in 3.5 million, and why Gaussian noise models are badly wrong for heavy-tailed data.

Worked example 2.4.2a four-sigma false alarm rate
Problem

A detector raises an alarm whenever a standardised noise sample exceeds $4$. Bound the false-alarm probability $Q(4)$ with Theorem 3, and estimate the number of false alarms in $10^6$ independent noise samples.

Approach

The bounds in (4) need only $\phi(4)$, which is elementary. Their ratio tells us how much we can trust them without any table.

Solution

  1. Density at 4. $\phi(4) = \frac{1}{\sqrt{2\pi}}e^{-8} = 0.39894 \times 3.3546 \times 10^{-4} = 1.3383 \times 10^{-4}$.

  2. Two-sided bound. By (4) with $z = 4$, $$\frac{4}{17}\,\phi(4) = 3.149 \times 10^{-5} \;\le\; Q(4) \;\le\; \frac{\phi(4)}{4} = 3.346 \times 10^{-5}.$$ The ratio of the bounds is $(1 + z^2)/z^2 = 17/16$, so either end is within $6.25\%$ of $Q(4)$.

  3. Chernoff-type bound. (5) gives $Q(4) \le \frac12 e^{-8} = 1.68 \times 10^{-4}$, correct but five times too large: it drops the $1/z$ factor.

  4. Expected alarms. The number of alarms in $n = 10^6$ samples is Binomial$(n, Q(4))$ with mean $n\,Q(4) \in [31.5, 33.5]$. (The exact value is $Q(4) = 3.167 \times 10^{-5}$.)

Result

$3.15 \times 10^{-5} \le Q(4) \le 3.35 \times 10^{-5}$: about $32$ false alarms per million samples. For $z \gtrsim 3$, $\phi(z)/z$ is already an accurate approximation to $Q(z)$, and it is the one to remember.

§ 03 MomentsStein's identity

The relation $\phi'(z) = -z\phi(z)$ used three times above is worth turning into a tool.

Theorem 4Stein's identity

Let $Z \sim \mathcal N(0,1)$ and $g$ continuously differentiable with $\E|g'(Z)| < \infty$, $\E|Z g(Z)| < \infty$ and $g(z)\phi(z) \to 0$ as $|z| \to \infty$. Then

$$\E[Z\, g(Z)] = \E[g'(Z)]. \tag{6}$$
Proof

Integrate by parts on $[-R, R]$ with $z\phi(z) = -\phi'(z)$:

$$\int_{-R}^{R} g(z)\, z\phi(z) \d z = -\int_{-R}^{R} g(z)\phi'(z) \d z = \Big[-g(z)\phi(z)\Big]_{-R}^{R} + \int_{-R}^{R} g'(z)\phi(z) \d z.$$

Let $R \to \infty$. The boundary term tends to $0$ by assumption, and both integrals converge to the full integrals because the integrands are absolutely integrable. ∎

With $g(z) = z^{n-1}$ (all hypotheses hold because polynomials times $\phi$ are integrable and vanish at infinity) we get the recursion $\E[Z^n] = (n-1)\,\E[Z^{n-2}]$. Starting from $\E[Z^0] = 1$ and $\E[Z] = 0$,

$$\E[Z^{2k+1}] = 0, \qquad \E[Z^{2k}] = (2k-1)(2k-3)\cdots 3 \cdot 1 = \frac{(2k)!}{2^k\, k!}. \tag{7}$$

In particular $\E[Z^4] = 3$: the Gaussian has kurtosis $3$, the reference value for "excess kurtosis". Stein's identity also characterises the Gaussian (if (6) holds for all bounded smooth $g$, then $Z$ is standard normal). That characterisation is the starting point of Stein's method for proving central limit theorems, and, in machine learning, of kernel Stein discrepancies and Stein variational gradient descent.

Worked example 2.4.3moments by Stein's identity
Problem

(a) For $X \sim \mathcal N(\mu, \sigma^2)$, show $\E[(X - \mu)\,g(X)] = \sigma^2\,\E[g'(X)]$ and use it to find $\E[X^3]$. (b) For $Z \sim \mathcal N(0, 1)$, compute $\E[Z\,\Phi(Z)]$ and the correlation between $Z$ and $\Phi(Z)$.

Approach

Transfer Theorem 4 to $X$ by writing $X = \mu + \sigma Z$. Then choose $g$ so that $\E[(X-\mu)g(X)]$ contains the moment we want and $g'$ is something we already know. For (b), $g = \Phi$ has $g' = \phi$, and $\E[\phi(Z)]$ is a Gaussian integral.

Solution

  1. General identity. Let $h(z) = g(\mu + \sigma z)$, so $h'(z) = \sigma g'(\mu + \sigma z)$. By (6), $$\E[(X - \mu)g(X)] = \sigma\,\E[Z\,h(Z)] = \sigma\,\E[h'(Z)] = \sigma^2\,\E[g'(X)].$$

  2. Third moment. Take $g(x) = x^2$: $\E[X^3] - \mu\E[X^2] = 2\sigma^2\E[X] = 2\sigma^2\mu$. With $\E[X^2] = \mu^2 + \sigma^2$, $$\E[X^3] = \mu(\mu^2 + \sigma^2) + 2\mu\sigma^2 = \mu^3 + 3\mu\sigma^2.$$

  3. (b) Apply Stein with $g = \Phi$. $\Phi$ and $\phi$ are bounded, so the hypotheses hold, and $\E[Z\Phi(Z)] = \E[\phi(Z)] = \int \phi(z)^2 \d z$.

  4. (b) Gaussian integral. $\phi(z)^2 = \frac{1}{2\pi}e^{-z^2}$, and substituting $x = \sqrt2 z$ in (2) gives $\int e^{-z^2}\d z = \sqrt\pi$. So $$\E[Z\,\Phi(Z)] = \frac{\sqrt\pi}{2\pi} = \frac{1}{2\sqrt\pi} \approx 0.282.$$

  5. (b) Correlation. $\Phi(Z) \sim \text{Uniform}(0, 1)$ (probability integral transform, lesson 2.3 exercise 3), so it has variance $\frac1{12}$, and $\E[Z] = 0$ gives $\Cov[Z, \Phi(Z)] = \frac1{2\sqrt\pi}$. Hence $\rho = \frac{1/(2\sqrt\pi)}{1 \cdot \sqrt{1/12}} = \sqrt{3/\pi} \approx 0.977$.

Result

$\E[X^3] = \mu^3 + 3\mu\sigma^2$; $\E[Z\Phi(Z)] = 1/(2\sqrt\pi)$ and $\rho_{Z, \Phi(Z)} = \sqrt{3/\pi}$. Stein's identity turns "integrate $z$ times something" into "differentiate the something", which is often the only easy direction.

§ 04 In codeTails, bounds and moments numerically

§ 05 PracticeExercises

  1. Let $X \sim \mathcal N(\mu, \sigma^2)$ and $a \ne 0$. Show $aX + b \sim \mathcal N(a\mu + b, a^2\sigma^2)$.core

    Solution

    Write $X = \mu + \sigma Z$ (Theorem 2). Then $aX + b = (a\mu + b) + a\sigma Z$. If $a > 0$ this is of the form $\mu' + \sigma' Z$ with $\sigma' = a\sigma$, so Theorem 2 applies. If $a < 0$, write it as $(a\mu + b) + |a|\sigma(-Z)$ and note $-Z \sim \mathcal N(0,1)$ because $\phi$ is even: $\P[-Z \le z] = \P[Z \ge -z] = 1 - \Phi(-z) = \Phi(z)$.

  2. Show $\E|Z| = \sqrt{2/\pi}$, and hence that for $X \sim \mathcal N(\mu,\sigma^2)$ the mean absolute deviation is $\sigma\sqrt{2/\pi} \approx 0.80\,\sigma$.core

    Solution

    From the proof of Theorem 2, $\E|Z| = 2\phi(0) = 2/\sqrt{2\pi} = \sqrt{2/\pi}$. And $|X - \mu| = \sigma|Z|$.

  3. A bit $s \in \{-A, +A\}$ is sent over a channel that adds $N \sim \mathcal N(0, \sigma^2)$, and the receiver decides by the sign of $s + N$. Show the error probability is $Q(A/\sigma)$. Use (5) to find an SNR $A/\sigma$ that guarantees an error rate of at most $10^{-6}$, and compare with the exact requirement.core

    Solution

    Given $s = +A$, an error is $A + N < 0$, i.e. $N/\sigma < -A/\sigma$, with probability $\Phi(-A/\sigma) = Q(A/\sigma)$; the case $s = -A$ is symmetric. Requiring $\tfrac12 e^{-z^2/2} \le 10^{-6}$ gives $z \ge \sqrt{2\ln(5 \cdot 10^5)} \approx 5.12$. The exact requirement is $z \ge Q^{-1}(10^{-6}) \approx 4.75$: the bound costs about $0.65$ dB.

  4. Show that $\E[e^{tZ}] = e^{t^2/2}$ for every real $t$, and deduce $\E[e^{tX}]$ for $X \sim \mathcal N(\mu,\sigma^2)$.core

    Solution

    Complete the square: $tz - z^2/2 = t^2/2 - (z - t)^2/2$. So $\E[e^{tZ}] = e^{t^2/2}\int \frac{1}{\sqrt{2\pi}}e^{-(z-t)^2/2}\d z = e^{t^2/2}$, the integral being that of the $\mathcal N(t,1)$ density. Then $\E[e^{tX}] = e^{t\mu}\E[e^{t\sigma Z}] = e^{t\mu + t^2\sigma^2/2}$. This is the moment generating function of lesson 4.5; expanding both sides in powers of $t$ recovers (7).

  5. Use Stein's identity to show $\E[Z^2 g(Z)] = \E[g(Z)] + \E[g''(Z)]$ for suitably regular $g$, and evaluate $\E[Z^2 \cos Z]$.stretch

    Solution

    Apply (6) to $h(z) = z g(z)$: $\E[Z \cdot Z g(Z)] = \E[h'(Z)] = \E[g(Z)] + \E[Z g'(Z)]$, and apply (6) again to the last term with $g'$: $\E[Z g'(Z)] = \E[g''(Z)]$. For $g = \cos$, $g'' = -\cos$, so $\E[Z^2\cos Z] = 0$. (Check: $\E[\cos Z] = e^{-1/2}$, the real part of $\E[e^{iZ}]$, which completing the square as in exercise 4 gives; the two terms cancel.)
