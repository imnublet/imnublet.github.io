The axioms of probability

Three axioms, and every rule you have ever used for probabilities follows by proof.

Probability & multivariate data analysis 25 min Y&G ch. 1
After this lesson you can
  • state the three axioms of a probability measure;
  • derive from them the complement rule, monotonicity, inclusion–exclusion and the union bound;
  • prove continuity of probability along monotone sequences of events;
  • build a probability model on a finite or countable sample space from point masses.

§ 01 DefinitionThree axioms

A probability model is a sample space $\Omega$, a $\sigma$-algebra $\mathcal F$ of events (lesson 1.1), and a rule that assigns each event a number. Kolmogorov's insight (1933) was that three requirements on that rule are enough: everything else is a theorem.

Definitionprobability measure

A function $\P : \mathcal F \to \R$ is a probability measure if

  1. Non-negativity: $\P[A] \ge 0$ for every $A \in \mathcal F$;
  2. Normalisation: $\P[\Omega] = 1$;
  3. Countable additivity: for pairwise disjoint $A_1, A_2, \dots \in \mathcal F$, $$\P\Big[\bigcup_{i=1}^\infty A_i\Big] = \sum_{i=1}^\infty \P[A_i]. \tag{1}$$

The triple $(\Omega, \mathcal F, \P)$ is a probability space.

The axioms say nothing about which numbers are right for a given experiment; that is the modelling step, informed by symmetry, physics or data. They only rule out assignments that are internally inconsistent. The usual reading is frequentist, $\P[A]$ being the long-run fraction of runs on which $A$ occurs, and each axiom is a property relative frequencies obviously have. The law of large numbers (lesson 5.1) later closes the loop: from the axioms alone it proves that relative frequencies converge to $\P[A]$.

§ 02 ConsequencesThe rules you already use, proved

Theorem 1elementary properties

For events $A, B$ in a probability space:

  1. $\P[\varnothing] = 0$;
  2. finite additivity: if $A_1, \dots, A_n$ are pairwise disjoint, $\P\big[\bigcup_{i=1}^n A_i\big] = \sum_{i=1}^n \P[A_i]$;
  3. $\P[A^c] = 1 - \P[A]$, and hence $\P[A] \le 1$;
  4. monotonicity: $A \subseteq B \Rightarrow \P[A] \le \P[B]$, and in fact $\P[B \setminus A] = \P[B] - \P[A]$;
  5. $\P[A \cup B] = \P[A] + \P[B] - \P[A \cap B]$.
Proof

(a) Take $A_1 = \Omega$ and $A_i = \varnothing$ for $i \ge 2$. These are pairwise disjoint with union $\Omega$, so (1) gives $1 = \P[\Omega] = 1 + \sum_{i \ge 2} \P[\varnothing]$. A series of identical non-negative terms is finite only if the terms are $0$, so $\P[\varnothing] = 0$.

(b) Pad the finite family with $A_i = \varnothing$ for $i > n$; the padded family is still pairwise disjoint and has the same union, and by (a) the extra terms contribute $0$ to (1).

(c) $A$ and $A^c$ are disjoint with union $\Omega$, so by (b) $1 = \P[A] + \P[A^c]$. Since $\P[A^c] \ge 0$, $\P[A] \le 1$.

(d) If $A \subseteq B$ then $B = A \cup (B \setminus A)$ with the two pieces disjoint, so $\P[B] = \P[A] + \P[B \setminus A]$. This is the formula for $\P[B \setminus A]$, and since $\P[B \setminus A] \ge 0$ it gives $\P[B] \ge \P[A]$.

(e) Use the two disjoint decompositions from exercise 1 of lesson 1.1: $A \cup B = A \cup (B \setminus A)$ and $B = (A \cap B) \cup (B \setminus A)$. By (b),

$$\P[A \cup B] = \P[A] + \P[B \setminus A], \qquad \P[B] = \P[A \cap B] + \P[B \setminus A].$$

Solve the second for $\P[B \setminus A]$ and substitute into the first. ∎

Rule (e) generalises to $n$ events. Write $A_J = \bigcap_{j \in J} A_j$ for a non-empty index set $J \subseteq \{1, \dots, n\}$.

Theorem 2inclusion–exclusion $$\P\Big[\bigcup_{i=1}^n A_i\Big] = \sum_{k=1}^{n} (-1)^{k+1} \sum_{\substack{J \subseteq \{1,\dots,n\} \\ |J| = k}} \P[A_J]. \tag{2}$$

Equivalently, $\P[\bigcup_i A_i] = \sum_{\varnothing \ne J} (-1)^{|J|+1} \P[A_J]$: add the singles, subtract the pairs, add the triples, and so on.

Proof

Induction on $n$. For $n = 1$ the formula reads $\P[A_1] = \P[A_1]$. Assume it holds for any $n$ events and let $U = \bigcup_{i=1}^n A_i$. By Theorem 1(e) and distributivity,

$$\P\Big[\bigcup_{i=1}^{n+1} A_i\Big] = \P[U] + \P[A_{n+1}] - \P\Big[\bigcup_{i=1}^n (A_i \cap A_{n+1})\Big].$$

Apply the hypothesis to both $n$-fold unions. The first gives $\P[U] = \sum_{\varnothing \ne J \subseteq [n]} (-1)^{|J|+1}\P[A_J]$: these are exactly the terms of (2) for $n+1$ events whose index set $J$ does not contain $n+1$. For the second, note $\bigcap_{j \in J} (A_j \cap A_{n+1}) = A_{J \cup \{n+1\}}$, so

$$-\P\Big[\bigcup_{i=1}^n (A_i \cap A_{n+1})\Big] = \sum_{\varnothing \ne J \subseteq [n]} (-1)^{|J|+2}\, \P[A_{J \cup \{n+1\}}] = \sum_{\substack{J' \subseteq [n+1],\ n+1 \in J' \\ |J'| \ge 2}} (-1)^{|J'|+1}\, \P[A_{J'}],$$

with $J' = J \cup \{n+1\}$, $|J'| = |J| + 1$. Together with $\P[A_{n+1}]$, which is the term $J' = \{n+1\}$ with sign $(-1)^{1+1} = +1$, these are exactly the terms of (2) whose index set does contain $n+1$. Adding both groups gives (2) for $n+1$ events. ∎

Exact formulas are often unnecessary; an upper bound that needs no intersections is usually what we want, for example when controlling the probability that any of many tests fails.

Theorem 3union bound (Boole's inequality)

For any events $A_1, A_2, \dots$ (disjoint or not),

$$\P\Big[\bigcup_{i=1}^\infty A_i\Big] \le \sum_{i=1}^\infty \P[A_i]. \tag{3}$$
Proof

Disjointification. Let $B_1 = A_1$ and $B_k = A_k \setminus \bigcup_{j < k} A_j$ for $k \ge 2$, so $B_k$ is "the first $A$ that $\omega$ lands in is $A_k$". Then:

  • the $B_k$ are pairwise disjoint: if $j < k$, then $B_k \subseteq A_j^c$ while $B_j \subseteq A_j$;
  • $\bigcup_k B_k = \bigcup_k A_k$: "$\subseteq$" since $B_k \subseteq A_k$; for "$\supseteq$", if $\omega \in \bigcup_k A_k$ let $k^*$ be the smallest $k$ with $\omega \in A_k$; then $\omega \in B_{k^*}$;
  • $B_k \subseteq A_k$, so $\P[B_k] \le \P[A_k]$ by monotonicity.

Hence $\P[\bigcup_k A_k] = \P[\bigcup_k B_k] = \sum_k \P[B_k] \le \sum_k \P[A_k]$. ∎

Worked example 1.2.1from three numbers to every Boolean combination
Problem

For events $A, B$ we know $\P[A] = 0.6$, $\P[B] = 0.5$ and $\P[A \cup B] = 0.8$. Find (a) $\P[A \cap B]$, (b) $\P[A \cap B^c]$, (c) the probability that exactly one of $A, B$ occurs, and (d) the probability that neither occurs. (e) If instead only $\P[A]$ and $\P[B]$ were known, what could be said about $\P[A \cap B]$?

Approach

Two events cut $\Omega$ into four disjoint pieces: $AB$, $AB^c$, $A^cB$, $A^cB^c$. Find the probability of each piece from the data with Theorem 1, then add pieces: every event built from $A$ and $B$ is a disjoint union of pieces.

Solution

  1. Intersection. By Theorem 1(e), $\P[A \cap B] = \P[A] + \P[B] - \P[A \cup B] = 0.6 + 0.5 - 0.8 = 0.3$.

  2. The other pieces. By Theorem 1(d) with $A \cap B \subseteq A$: $\P[AB^c] = \P[A] - \P[AB] = 0.3$. Likewise $\P[A^cB] = 0.5 - 0.3 = 0.2$. The fourth piece is the complement of the union: $\P[A^cB^c] = 1 - \P[A \cup B] = 0.2$ by Theorem 1(c) and De Morgan. Check: $0.3 + 0.3 + 0.2 + 0.2 = 1$.

  3. Combine. "Exactly one" is the disjoint union $AB^c \cup A^cB$, so it has probability $0.3 + 0.2 = 0.5$; "neither" is $A^cB^c$, probability $0.2$.

  4. Bounds without the union. Monotonicity gives $\P[AB] \le \min(\P[A], \P[B]) = 0.5$. From Theorem 1(e) and $\P[A \cup B] \le 1$, $\P[AB] = \P[A] + \P[B] - \P[A \cup B] \ge 0.6 + 0.5 - 1 = 0.1$. Both ends are attained: $B \subseteq A$ gives $0.5$, and $A \cup B = \Omega$ gives $0.1$.

Result

(a) $0.3$, (b) $0.3$, (c) $0.5$, (d) $0.2$, and (e) $0.1 \le \P[A \cap B] \le 0.5$ with no further information. Marginal probabilities never determine a joint one; they only bound it. These are the Fréchet bounds.

§ 03 LimitsContinuity of probability

Countable additivity is what lets probabilities pass to the limit. A sequence of events is increasing if $A_1 \subseteq A_2 \subseteq \cdots$, with limit $\bigcup_n A_n$, and decreasing if $A_1 \supseteq A_2 \supseteq \cdots$, with limit $\bigcap_n A_n$.

Theorem 4continuity

If $A_n \uparrow A = \bigcup_n A_n$, then $\P[A_n] \to \P[A]$. If $A_n \downarrow A = \bigcap_n A_n$, then $\P[A_n] \to \P[A]$.

Proof

Increasing. Set $B_1 = A_1$ and $B_k = A_k \setminus A_{k-1}$. Because the sequence increases, this is the disjointification from Theorem 3, so the $B_k$ are pairwise disjoint, $\bigcup_{k \le n} B_k = A_n$ and $\bigcup_k B_k = A$. Then

$$\P[A] = \sum_{k=1}^\infty \P[B_k] = \lim_{n\to\infty} \sum_{k=1}^n \P[B_k] = \lim_{n\to\infty} \P[A_n],$$

where the first equality is (1), the second is the definition of a series, and the third is finite additivity.

Decreasing. $A_n^c$ increases to $\bigcup_n A_n^c = \big(\bigcap_n A_n\big)^c = A^c$ by De Morgan, so $1 - \P[A_n] = \P[A_n^c] \to \P[A^c] = 1 - \P[A]$. ∎

Why it matters

Continuity is how we compute $\P[X \le x] = \lim_{n} \P[X \le x + 1/n]$ (right-continuity of CDFs, lesson 2.3) and $\P[\text{a head eventually}] = \lim_n \P[\text{a head in } n \text{ tosses}] = 1$. It is, in fact, equivalent to countable additivity given finite additivity.

§ 04 Building modelsPoint masses on countable spaces

On a countable $\Omega$ a probability measure is completely determined by the probabilities of single outcomes, and any non-negative assignment that sums to one works.

Theorem 5discrete probability models

Let $\Omega$ be countable and $p : \Omega \to [0,1]$ with $\sum_{\omega \in \Omega} p(\omega) = 1$. Then $\P[A] = \sum_{\omega \in A} p(\omega)$ defines a probability measure on $2^\Omega$. Conversely, every probability measure on $2^\Omega$ arises this way, with $p(\omega) = \P[\{\omega\}]$.

Proof

Series of non-negative terms can be summed in any order and grouped arbitrarily, so the sum over $A$ is well defined. Non-negativity and normalisation are immediate. For disjoint $A_i$, the terms of $\sum_{\omega \in \cup_i A_i} p(\omega)$ split into the groups $\omega \in A_i$, each $\omega$ appearing in exactly one group, so it equals $\sum_i \sum_{\omega \in A_i} p(\omega)$: this is (1). Conversely, any $A \subseteq \Omega$ is the countable disjoint union of the singletons $\{\omega\}$, $\omega \in A$, so (1) forces $\P[A] = \sum_{\omega \in A} \P[\{\omega\}]$. ∎

The special case of a finite $\Omega$ whose outcomes are equally likely, $p(\omega) = 1/|\Omega|$, gives the classical formula

$$\P[A] = \frac{|A|}{|\Omega|}, \tag{4}$$

which turns probability into counting (lesson 1.5). Equal likelihood is an assumption about the experiment, not a consequence of the axioms, and it depends on the sample space: three fair tosses make the 8 sequences equally likely, but not the 4 head-counts.

Worked example 1.2.2a loaded die
Problem

A die is loaded so that face $k$ comes up with probability proportional to $k$. Find the model, the probability of an even face, and the probability that the face is even or at least $4$.

Approach

On a finite $\Omega$, Theorem 5 says it is enough to choose the point masses: fix the constant by normalisation, then sum point masses over each event. Use inclusion–exclusion for the union and confirm by direct listing.

Solution

  1. Normalise. $p(k) = ck$ for $k = 1, \dots, 6$ and $\sum_k p(k) = c \cdot 21 = 1$, so $c = \frac1{21}$. All $p(k) \ge 0$, so by Theorem 5 $\P[A] = \sum_{k \in A} k/21$ is a probability measure on $2^\Omega$.

  2. Even face. $E = \{2, 4, 6\}$: $\P[E] = (2 + 4 + 6)/21 = 12/21 = \frac47$. (Compare $\frac12$ for a fair die.)

  3. Union by inclusion–exclusion. With $G = \{4, 5, 6\}$, $\P[G] = 15/21$ and $E \cap G = \{4, 6\}$ has $\P[E \cap G] = 10/21$, so $$\P[E \cup G] = \frac{12}{21} + \frac{15}{21} - \frac{10}{21} = \frac{17}{21}.$$

  4. Check by listing. $E \cup G = \{2, 4, 5, 6\}$ and $(2 + 4 + 5 + 6)/21 = 17/21$. ✓ Equivalently, the complement $\{1, 3\}$ has probability $4/21$.

Result

$p(k) = k/21$, $\P[\text{even}] = \frac47 \approx 0.571$ and $\P[\text{even or} \ge 4] = \frac{17}{21} \approx 0.810$. The equally likely formula (4) does not apply here; the general point-mass sum does.

§ 05 In codeChecking inclusion–exclusion exactly

With exact rational arithmetic, (2) can be checked on any finite model, including one with non-uniform point masses.

§ 06 PracticeExercises

  1. Prove Bonferroni's inequality $\P[A \cap B] \ge \P[A] + \P[B] - 1$, and its $n$-event form $\P\big[\bigcap_{i=1}^n A_i\big] \ge 1 - \sum_{i=1}^n \P[A_i^c]$.core

    Solution

    From Theorem 1(e), $\P[A \cap B] = \P[A] + \P[B] - \P[A \cup B] \ge \P[A] + \P[B] - 1$. For $n$ events, De Morgan and the union bound give $\P\big[\bigcap_i A_i\big] = 1 - \P\big[\bigcup_i A_i^c\big] \ge 1 - \sum_i \P[A_i^c]$. This is how simultaneous confidence statements are built: if each of $n$ intervals fails with probability $\alpha/n$, all hold with probability at least $1 - \alpha$.

  2. The symmetric difference is $A \,\triangle\, B = (A \setminus B) \cup (B \setminus A)$. Show $\P[A \triangle B] = \P[A] + \P[B] - 2\P[A \cap B]$.core

    Solution

    The two pieces are disjoint, and by Theorem 1(d) applied to $A \cap B \subseteq A$, $\P[A \setminus B] = \P[A \setminus (A \cap B)] = \P[A] - \P[A \cap B]$; likewise for $B \setminus A$. Add the two.

  3. Toss a fair coin until the first head and let $\Omega = \{1, 2, \dots\}$ record the toss on which it appears, with $p(k) = 2^{-k}$. Check this is a valid model, and compute the probability that the first head comes on an even-numbered toss.core

    Solution

    $\sum_{k \ge 1} 2^{-k} = \frac{1/2}{1 - 1/2} = 1$, so Theorem 5 applies. Then $\P[\text{even}] = \sum_{m \ge 1} 2^{-2m} = \sum_{m \ge 1} 4^{-m} = \frac{1/4}{1 - 1/4} = \frac13.$

  4. Show that there is no probability measure on $\Omega = \N$ under which all outcomes are equally likely.core

    Solution

    Suppose $\P[\{n\}] = c$ for all $n$. By (1), $1 = \P[\N] = \sum_{n} c$, which is $0$ if $c = 0$ and $\infty$ if $c > 0$. Either way a contradiction. Finite additivity alone would not rule this out; countable additivity does.

  5. Let $A_n$ be the event that the first $n$ tosses of a fair coin are all tails. Use continuity to find the probability that the coin never shows heads.stretch

    Solution

    $A_n$ is decreasing and $\bigcap_n A_n$ is "all tosses are tails". On the first $n$ tosses $\P[A_n] = 2^{-n}$ (one of $2^n$ equally likely sequences). By Theorem 4, $\P[\bigcap_n A_n] = \lim_n 2^{-n} = 0$: a head eventually appears with probability one.
